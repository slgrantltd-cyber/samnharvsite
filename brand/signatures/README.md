# Email signatures

Two files: `samuel.html`, `harvey.html`. The mark image is served from https://samnharv.vercel.app/brand/mark-gold.png
(the always-on Vercel project, deployed via CLI) so it works without waiting
for a push. The same file also lives in `public/brand/` on the main site.

## Gmail
1. Open the HTML file in a browser (double-click it).
2. Select all (⌘A), copy (⌘C).
3. Gmail → Settings → See all settings → General → Signature → Create new → paste (⌘V) → Save.

## Titan webmail
Settings → Signature → switch to the HTML/"<>" editor → paste the file's source → Save.

## Apple Mail
Mail → Settings → Signatures → create one, paste the rendered block from the browser; untick "Always match my default message font".

Gold is a flat #c9ab7c in email (gradients don't render reliably in mail clients); the mark image carries the glossy line.
